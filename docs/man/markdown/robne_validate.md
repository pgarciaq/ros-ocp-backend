## robne validate

Validate ROS CSV input without computing recommendations

```
robne validate [flags]
```

### Options

```
      --config string       YAML overlay (skips ./robne.yaml; still overlays the user file)
  -h, --help                help for validate
      --input stringArray   directory, .csv, .tar.gz, or postgres:// URL (recompute from stored digests); repeatable — the first payload is the primary (recommendation cluster), later payloads are advisory context (e.g. the HCP management cluster's topology)
      --no-user-config      skip user YAML/JSON (same as ROBNE_NO_USER_CONFIG=1)
      --now string          RFC3339 decay/staleness clock (does not slide term windows; default is max interval_end)
      --plugins string      comma-separated allowlist (default: all shipped plugins; omit to skip missing inputs)
```
