## Reporting Issues

If you find a bug or have a feature request, please open an issue on the project's GitHub repository with:

1. A clear description of the problem or enhancement
2. Steps to reproduce (for bugs)
3. Expected vs actual behavior
4. Environment details (Go version, OS, cluster version)
